# ПРОДАЙ САМ — React/Vite landing

Landing page rebuilt as React + Vite + TypeScript + Tailwind CSS + lucide-react.

The design keeps the existing "Продай сам" content structure and adds the calm, editorial, scroll-driven dynamics requested: floating navigation, full-screen hero, overlapping cream section, sticky desktop system navigation, reveal-on-scroll cards, mobile-first layout, 20-stage CTA, FAQ and contact form.

Run:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
